# UI mocks

Static HTML mocks of the three directions explored for v2 (open any file in a browser; they need the canvas runtime for
`sc-for` loops, so some boards show placeholders when opened directly). Live canvas:
https://claude.ai/artifact/JLHbVikWiz5r97M432VJGh

**Chosen: C · Rhythm** (`C-*.dc.html`), following the system light/dark setting. A and B are kept for reference;
some of their ideas are reusable (A's multi-change approval list, A's chat with a disambiguation choice and a recurring
scope picker, B's STALE/VERIFIED apply report with Undo, B's Backlog with "Needs a look").
